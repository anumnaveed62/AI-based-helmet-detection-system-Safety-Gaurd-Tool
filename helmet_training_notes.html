YOLOv8 Helmet Detection Training — Troubleshooting Notes

Root cause found: The laptop has only an Intel UHD Graphics 620 (integrated, no CUDA support), and PyTorch installed is the CPU-only build (2.13.0+cpu). Because CPU training is slow, the training runs for helmet_train, helmet_train-2, and helmet_train-3 were interrupted (Ctrl+C) before completing even the first epoch — so no checkpoint (last.pt) was ever saved, leaving empty weights/ folders and no results.csv.

Steps to Fix and Rerun Training

  1. Check your dataset size.

    Run this to see your data paths, then check how many images are in the train folder — more images means longer epochs on CPU, so this sets expectations before starting.

    import yaml
with open("D:/realtime-opencv-detection/helmet-dataset/data.yaml") as f:
    print(yaml.safe_load(f))
  2. Close other heavy programs.

    Since training runs entirely on CPU, close browser tabs, extra VS Code windows, or anything CPU-intensive so training gets as many resources as possible.

  3. Run the training script with CPU-friendly settings.

    Smaller image size and batch size, with the device explicitly set to CPU:

    from ultralytics import YOLO

model = YOLO("yolov8n.pt")

results = model.train(
    data="D:/realtime-opencv-detection/helmet-dataset/data.yaml",
    epochs=30,
    patience=10,
    imgsz=416,
    batch=8,
    name="helmet_train",
    exist_ok=True,
    device="cpu"
)
  4. Let it run without interrupting.
    Watch for the progress bar showing Epoch 1/30 with box_loss/cls_loss updating. Even if it moves slowly, that's normal — do not press Ctrl+C. This is exactly what caused the empty weights/ folders before: training was stopped before the first checkpoint could save.
  5. Confirm the first checkpoint saved.

    Once epoch 0 finishes, check that a checkpoint now exists:

    import os
print(os.listdir(r"D:\realtime-opencv-detection\runs\detect\helmet_train\weights"))

    You should see last.pt (and later best.pt). Once this file exists, you're safe to stop and resume later if needed — no more lost progress.

  6. If you must stop early, resume instead of restarting.

    Once a checkpoint exists, resume from where you left off instead of retraining from scratch:

    model = YOLO(r"D:/realtime-opencv-detection/runs/detect/helmet_train/weights/last.pt")
results = model.train(resume=True)
  7. Repeat for helmet_train-2 and helmet_train-3.

    Once helmet_train completes successfully and produces a results.csv, rerun the same training call with name="helmet_train-2", then name="helmet_train-3" — adjusting whatever settings you intended to compare between runs.

Extra Speed Tips for CPU-Only Training

  • Lower imgsz — 416 instead of 640 roughly halves compute cost per image.
  • Reduce dataset size for a first test run — validate the pipeline on a small subset before committing to a full run.
  • Use yolov8n.pt (nano) — already the lightest YOLOv8 variant, good choice for CPU.
  • Consider a cloud GPU (e.g., Google Colab's free GPU runtime) if local CPU training remains too slow for repeated experiments.

Plotting Results Once Training Completes

import pandas as pd
import matplotlib.pyplot as plt
import os

base = r"D:\realtime-opencv-detection\runs\detect"
folders = ["helmet_train", "helmet_train-2", "helmet_train-3"]

for folder in folders:
    csv_path = os.path.join(base, folder, "results.csv")
    if os.path.exists(csv_path):
        df = pd.read_csv(csv_path)
        df.columns = df.columns.str.strip()
        plt.plot(df['epoch'], df['train/box_loss'], label=f'{folder} train_box_loss')
        plt.plot(df['epoch'], df['val/box_loss'], label=f'{folder} val_box_loss')

plt.legend()
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.show()
